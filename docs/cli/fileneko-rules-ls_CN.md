# fileneko rules ls

[English](fileneko-rules-ls.md) | **简体中文**

列出全局规则或用户专用规则

## 概要（Synopsis）

列出全局规则或用户专用规则。

```
fileneko rules ls [flags]
```

## 选项（Options）

```
  -h, --help   ls 子命令帮助信息
```

## 继承自父命令的选项

```
  -c, --config string     配置文件路径
  -d, --database string   数据库文件路径（默认 "./filebrowser.db"）
  -i, --id uint           规则适用的用户 ID
  -u, --username string   规则适用的用户名
```
