# fileneko hash

[English](fileneko-hash.md) | **简体中文**

计算密码的哈希值

## 概要（Synopsis）

使用 bcrypt 算法计算密码哈希值。

```
fileneko hash <password> [flags]
```

## 选项（Options）

```
  -h, --help   hash 命令帮助信息
```

## 继承自父命令的选项

```
  -c, --config string     配置文件路径
  -d, --database string   数据库文件路径（默认 "./filebrowser.db"）
```
