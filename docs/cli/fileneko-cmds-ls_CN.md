# fileneko cmds ls

[English](fileneko-cmds-ls.md) | **简体中文**

列出每个事件所配置的所有命令

## 概要（Synopsis）

列出每个事件所配置的所有命令。

```
fileneko cmds ls [flags]
```

## 选项（Options）

```
  -e, --event string   事件名称（不含 'before' 或 'after'）
  -h, --help           ls 子命令帮助信息
```

## 继承自父命令的选项

```
  -c, --config string     配置文件路径
  -d, --database string   数据库文件路径（默认 "./filebrowser.db"）
```
