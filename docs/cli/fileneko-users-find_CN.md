# fileneko users find

[English](fileneko-users-find.md) | **简体中文**

按用户名或 ID 查找用户

## 概要（Synopsis）

按用户名或 ID 查找用户。若未指定任何参数，则打印所有用户。

```
fileneko users find <id|username> [flags]
```

## 选项（Options）

```
  -h, --help   find 命令帮助信息
```

## 继承自父命令的选项

```
  -c, --config string     配置文件路径
  -d, --database string   数据库文件路径（默认 "./filebrowser.db"）
```
