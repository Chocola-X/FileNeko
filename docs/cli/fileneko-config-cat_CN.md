# fileneko config cat

[English](fileneko-config-cat.md) | **简体中文**

打印当前配置

## 概要（Synopsis）

打印当前数据库中的配置信息。

```
fileneko config cat [flags]
```

## 选项（Options）

```
  -h, --help   cat 命令帮助信息
```

## 继承自父命令的选项

```
  -c, --config string     配置文件路径
  -d, --database string   数据库文件路径（默认 "./filebrowser.db"）
```
