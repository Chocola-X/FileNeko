# fileneko users export

[English](fileneko-users-export.md) | **简体中文**

导出所有用户到文件

## 概要（Synopsis）

将所有用户导出到 JSON 或 YAML 文件。请指定写入用户列表的目标文件路径。

```
fileneko users export <path> [flags]
```

## 选项（Options）

```
  -h, --help   export 子命令帮助信息
```

## 继承自父命令的选项

```
  -c, --config string     配置文件路径
  -d, --database string   数据库文件路径（默认 "./filebrowser.db"）
```
