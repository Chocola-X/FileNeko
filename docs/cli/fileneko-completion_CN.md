# fileneko completion

[English](fileneko-completion.md) | **简体中文**

为指定的 Shell 生成自动补全脚本

## 概要（Synopsis）

为指定的 Shell 生成 FileNeko 的自动补全脚本。
详见各子命令的帮助信息以了解如何使用生成的脚本。

## 选项（Options）

```
  -h, --help   completion 命令帮助信息
```

## 继承自父命令的选项

```
  -c, --config string     配置文件路径
  -d, --database string   数据库文件路径（默认 "./filebrowser.db"）
```
