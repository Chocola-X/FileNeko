# fileneko users rm

[English](fileneko-users-rm.md) | **简体中文**

按用户名或 ID 删除用户

## 概要（Synopsis）

按用户名或 ID 删除指定用户。

```
fileneko users rm <id|username> [flags]
```

## 选项（Options）

```
  -h, --help   rm 子命令帮助信息
```

## 继承自父命令的选项

```
  -c, --config string     配置文件路径
  -d, --database string   数据库文件路径（默认 "./filebrowser.db"）
```
