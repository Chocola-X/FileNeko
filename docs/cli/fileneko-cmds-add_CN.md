## 概要（Synopsis）

添加在特定事件触发时执行的命令。

```
fileneko cmds add <event> <command> [flags]
```

## 选项（Options）

```
  -h, --help   add 子命令帮助信息
```

## 继承自父命令的选项

```
  -c, --config string     配置文件路径
  -d, --database string   数据库文件路径（默认 "./filebrowser.db"）
```
