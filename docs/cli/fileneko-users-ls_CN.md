# fileneko users ls

[English](fileneko-users-ls.md) | **简体中文**

列出所有用户

## 概要（Synopsis）

列出数据库中的所有用户。

```
fileneko users ls [flags]
```

## 选项（Options）

```
  -h, --help   ls 子命令帮助信息
```

## 继承自父命令的选项

```
  -c, --config string     配置文件路径
  -d, --database string   数据库文件路径（默认 "./filebrowser.db"）
```
