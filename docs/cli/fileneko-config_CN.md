# fileneko config

[English](fileneko-config.md) | **简体中文**

配置管理工具

## 概要（Synopsis）

配置管理工具。

## 选项（Options）

```
  -h, --help   config 命令帮助信息
```

## 继承自父命令的选项

```
  -c, --config string     配置文件路径
  -d, --database string   数据库文件路径（默认 "./filebrowser.db"）
```
