# fileneko version

[English](fileneko-version.md) | **简体中文**

打印版本号

## 概要（Synopsis）

打印软件版本号。

```
fileneko version [flags]
```

## 选项（Options）

```
  -h, --help   version 命令帮助信息
```

## 继承自父命令的选项

```
  -c, --config string     配置文件路径
  -d, --database string   数据库文件路径（默认 "./filebrowser.db"）
```
